# MysteryFish

MysteryFish is a fish-themed game with a browser frontend and an Express/MongoDB backend.

- Frontend setup and gameplay: [frontend/README.md](frontend/README.md)
- Backend setup and API: [backend/README.md](backend/README.md)

Do not commit local `.env` files. Copy `backend/.env.example` to `backend/.env` and configure it for your environment.
